Glowify is a full-stack AI-powered skincare and wellness platform designed to provide personalized skin analysis, smart skincare recommendations, and wellness-aware beauty guidance.

The platform combines AI face scanning, skincare intelligence, health tracking, and ingredient-based recommendations to help users maintain healthier skin through personalized insights.

Unlike traditional skincare applications, Glowify considers internal health factors such as hormonal imbalance, period cycles, and lifestyle conditions that may affect skin quality.

---

# 🌍 Problem Statement

Many users struggle with:

* ❌ Choosing incorrect skincare products
* ❌ Lack of personalized skincare guidance
* ❌ Skin issues caused by internal health conditions
* ❌ Expensive dermatologist consultations
* ❌ Limited awareness about harmful skincare chemicals
* ❌ Generic skincare routines unsuitable for different skin types

This often leads to:

* Skin irritation and damage
* Increased acne and pigmentation
* Wasted money on ineffective products
* Reduced self-confidence

# 🧪 How to Run Locally

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/glowify.git
cd glowify
```

---

## 2️⃣ Install Dependencies

```bash
npm install
```

---

## 3️⃣ Configure Supabase

Create Supabase configuration inside:

```bash
src/lib/supabase.ts
```

Add your Supabase credentials.

---

## 4️⃣ Setup Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

---

## 5️⃣ Start Development Server

```bash
npm run dev
```

Application runs at:

```bash
http://localhost:5173
```
